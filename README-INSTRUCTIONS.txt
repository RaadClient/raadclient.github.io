RAAD CLIENT WEBSITE — HOME PAGE

Files:
- index.html        Main landing page
- assets/raad-logo.png   Raad emblem used by the page

PUBLISH:
1. Open your GitHub repository: raadclient.github.io
2. Click Add file > Upload files.
3. Upload index.html and the assets folder (including raad-logo.png).
4. Commit changes to the main branch.
5. Wait for GitHub Pages to deploy, then visit https://raadclient.github.io
