A look at the features planned for the Raad Client project.

Performance Focus

A lightweight experience is a key goal, with attention to smooth gameplay and efficient resource use.

⚔

PvP Client — 1.8.9

A dedicated client experience planned around the Minecraft 1.8.9 PvP community.

Custom HUD

A customizable heads-up display to help organize useful in-game information.

⌨

PvP HUD Elements

Planned visual elements may include keystrokes, CPS, FPS and other helpful indicators.

Customization

Options to personalize the interface and adjust supported client features.

Multi-Version Launcher

A launcher planned to support Vanilla, Forge and Fabric across multiple Minecraft versions.

☁

Cloud Settings

Optional account-based settings synchronization is part of the project vision.

🧩

Mod Support

A flexible setup designed with supported mods and client-side customization in mind.

🔒

Account System

A planned account system with Free and Premium options and secure sign-in.
